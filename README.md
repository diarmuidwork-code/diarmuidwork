# Space Invaders (for iMac)

A lightweight Space Invaders-style game written in pure Python with `tkinter` (which ships with standard Python on macOS), so you can run it directly on an iMac without extra dependencies.

## Run

```bash
python3 space_invaders.py
```

## Controls

- **Left / Right arrows**: move
- **Space**: fire
- **R**: restart after game over

## Notes

- Starts at Level 1 and gets harder each wave.
- Score increases by 10 per invader.
- Shields absorb enemy and player shots until broken.
